# 作品导航

任务分流和交付见[仓库入口](../AGENTS.md)。只给书名时，按下表选与任务相符的正文。

| 作品 | 正文选择 | 按需查阅 |
|---|---|---|
| [感染体](感染体/) | 排查广告、OCR 或异文用《感染体（完整版）》。查原作前情或拆书默认用《感染体（精校版）》。分析补写后的故事用《感染体（精校补全版）》。 | 对照同目录的精校变更日志、缺章与 OCR 勘误清单、缺章补写卷。原缺第 697、709、724、726–732、736 节；补写版中相关结论注明“补写”。现有卷纲、章纲和全鉴供交叉检查。 |
| [科普卢：余烬苍穹](科普卢：余烬苍穹/) | 全书范围先定位《科普卢：余烬苍穹（全十卷完整版）》；卷内事件查“分卷正文”。处理单章可按章号找“逐章稿件与状态卡”的 `ch_*.txt`；`state_*.txt` 为旁证，覆盖范围以实际文件为准。 | 细纲记录计划，正史校对记录来源与分歧，资料卡提供检索线索。部分文档沿用《星海余烬》旧题；“旧版全本”用于对照。核对星际正史时分别标明小说原创、作品正文与可核实的官方出处。 |

核对相邻章时优先沿用同一套正文。同系列分卷稿可跨卷连读。缺少目标卷章时，查同一作品的其他正文并标明从哪个卷章换用哪份稿件。引用写明具体文件名、章题和该文件内的位置。异文会改变剧情判断时，列出两处依据；无法确定采用哪版时，列出章名和差异向用户确认。

查前情、核对衔接或起草续写时，用[续写与连续性核对](../.agents/skills/novel-continuity/SKILL.md)。润色先看本书邻章和同角色对白，保留称谓、专名、知情范围和有叙事作用的重复。

新作品按正文、设定、计划、校对记录辨识来源。交付派生资料时列出输入版本、产物及待核项。单次任务的书名、人物与情节留在作品材料中。

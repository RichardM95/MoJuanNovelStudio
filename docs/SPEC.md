# 墨卷 Novel Studio MVP
Windows 优先、离线 Tauri 2 + Rust + React/TypeScript + SQLite 小说写作工具。无账号、网络同步或 AI。
书架含作品新增、改名、作者、回收站删除/恢复；作品含卷与章，新增改名排序；章节纯文本编辑；编号从顺序派生。
保存 800ms 防抖、串行持久化、revision 防旧覆盖。切章/离开前 flush，失败保留草稿。中文 IME 期间不重建编辑器。
整书 TXT 输出含书名、作者、卷章，UTF-8 和 CRLF，先保存后导出。备份/恢复以版本化全书库 JSON 作为可移植格式，恢复先验证后事务写入，不能半导入。SQLite 本地数据库为唯一生产真相源。
作品、卷、章均可软删除和恢复；回收站永久删除需输入名称确认，按父子关系级联。桌面单实例，默认不加载远程网页。
测试包括迟到保存、非法树引用、重排、删除恢复、乱码/换行、备份拒绝、真实 SQLite 重开。Windows 安装能力与 Linux 测试分开报告。

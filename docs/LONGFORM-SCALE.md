# 墨卷：300 章与 1,000 章合成书库实测

使用原有 `qa/longform-scale` 的独立可选模式。由正式 Rust 服务建立三个卷，写入每章 8,192 个 Unicode 标量的合成中文模板（包括换行和少量特殊字符），不是实际稿件。1,000 章深历史库从同一关库后的浅库复制；前 24 章各新增 64 条历史，最后存回原样正文。所有当前正文与 ID 逐字节核对，因而浅/深比较不掺杂当前稿长度变化。两档并非所有章节同等深。

每档三次、总共九个独立进程。每次先复制已关闭的基准文件，在副本上测量：打开服务、全库正文读、目录、首/中/末章的三次点读、首章历史首页与具体版本、依据保存前版本的服务保存（包括返回全库状态）。保存后做真实 SQLite 备份，再另存一版；测恢复预备与提交（含生成恢复前快照），最后重开副本核对恢复到备份，并另开快照核对后来修改。复制、逐字节校验和轮次清理未计入各项操作耗时；未清理 OS 文件缓存。目录和点读是服务代理指标，不是 WebView 切章渲染，也不含界面、IPC 或真实创作时间。三样本范围只代表这次运行，不是稳定 SLA。

## 复跑

```sh
cargo build --release --locked --manifest-path qa/longform-scale/Cargo.toml
python3 scripts/longform_scale.py \
  --binary qa/longform-scale/target/release/mojuan-longform-scale \
  --profile release --large-scenes --wall-seconds 900
```

若设置 `CARGO_TARGET_DIR`，将 `--binary` 改为该目录下的 release 可执行文件。Linux 监督器隔离生成文件并保存机器、时间、磁盘和内存证据；已有 24 章默认模式、`--smoke` 和文件上限检查保持原来用法。

## 本次观测

Linux x86_64 云机；可见 AMD EPYC 9V74、9 个逻辑 CPU、约 9.7 GiB 内存；cgroup CPU/内存配额不可见，不假定独享。Rust 1.91.1 release、锁定的 bundled SQLite 3.54.1。基准文件已关库，复制前没有活跃 WAL；下表为逻辑字节。

| 样本 | 当前正文 UTF‑8（标量） | 历史条数（含初始空稿） | 历史正文 UTF‑8 | 已关闭 SQLite |
|---|---:|---:|---:|---:|
| 300 章浅历史 | 7,252,425（2,457,600） | 600 | 7,252,425 | 15,171,584 |
| 1,000 章浅历史 | 24,174,750（8,192,000） | 2,000 | 24,174,750 | 50,020,352 |
| 1,000 章深历史 | 24,174,750（8,192,000） | 3,536 | 61,307,166 | 88,358,912 |

三轮操作范围（毫秒；选章点读为每档 3×3 次，其他为 3 次）：

| 操作 | 300 浅 | 1,000 浅 | 1,000 深 |

| 打开服务 | 0.95–1.33 | 1.18–1.54 | 1.07–1.26 |
| 读全库正文 | 17.18–21.14 | 57.78–191.86 | 51.27–60.95 |
| 读目录 | 1.87–2.77 | 6.23–18.67 | 6.82–8.37 |
| 选章点读 | 0.032–0.072 | 0.034–0.369 | 0.033–0.284 |
| 保存（含返回全库状态） | 17.24–20.39 | 53.98–57.61 | 56.38–99.57 |
| 查历史首页 / 取一版正文 | 0.081–0.104 / 0.065–0.067 | 0.088–0.105 / 0.067–0.115 | 0.114–0.143 / 0.068–0.165 |
| 备份 | 25.16–40.98 | 75.93–127.93 | 153.13–178.86 |
| 恢复预备 | 92.87–147.34 | 276.01–440.04 | 555.29–582.27 |
| 恢复提交（含恢复前快照） | 87.46–138.23 | 275.76–445.52 | 630.44–746.84 |

备份时主库 WAL 为 78,312–94,792 字节、SHM 为 32,768 字节，备份真实文件分别约 15.20 MB、50.04 MB、88.38–88.39 MB，恢复前快照约 15.22 MB、50.07 MB、88.41 MB。深库首章历史有 66 条，首页取 50 条并带续页游标；浅库首章首页为 2 条。这里测的是首页与一版正文，不是整库历史导出速度。

子进程高水位 RSS 分别约 23–24、56、57–58 MiB，包含进程启动，不含构建、GUI 和 OS 文件缓存。造成功例种库用了约 130 秒；九轮与种库合计约 140 秒，监督器观测工作树峰值 596,025,344 字节，不是容量上限。每一轮原始指标与流程边界见 [可复跑样本记录](../qa/acceptance/large-scenes.evidence)。

本次同稿深库的备份和恢复范围比浅库高，而目录、读正文、保存存在重叠或波动；不能据三个顺序样本宣称历史是每项耗时的唯一决定因素。未做冷缓存控制、Windows、WebView 或真实长篇验收。

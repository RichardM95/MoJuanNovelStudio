# 正文保存回执不明后的安全核对

- 保存队列拒绝把写入错误视为事务未提交；记录在途版本、拟写正文和代数。保存回执只在同一活动作品的章、下一版本及正文精确匹配时才采信。
- 后台通过已有 epoch 与该作品、该章的精确基线点读绑定可核对范围，普通保存不等待该结果。作者只读核对用 epoch 前后夹住现有库读取；结果迟到、接口不可用、书库更换或不匹配都不写入。
- 原基线仍在不能证明旧请求结束；仍禁止重发。只在下一版本及字节精确吻合时确认旧尝试，后来编辑保持未保存、只允许显式另存。
- 作者可随时复制当前稿，回执失败时提供选中编辑器正文以手动复制；无跨会话存储。测试模拟事务提交或不提交、回执不正确、停止/换范围晚回，旧真实 SQLite 用例作为提交边界对照。

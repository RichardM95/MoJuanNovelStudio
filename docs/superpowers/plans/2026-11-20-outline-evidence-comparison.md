# 大纲引文对照实施计划

1. 新建共享原创夹具，固定大纲/前文全文、精确引文、建议、自报说明和未决备注；先在 WritingPanel 测试中证实没有并排对照。
2. 仅通过已绑定 WritingPanel 详情接入只读组件。分别筛选实际大纲字段、前文 body；按 Unicode 标量校验并截取，不接受越界。新详情重置选择。复用响应式布局。
3. 在独立真实文件 SQLite 库通过 Service 与作品级 Broker 验证两份建议合法待审、显式保存未决备注、采纳失败不动正文历史，重开仍保存。
4. 补组件正反、切换、脏稿及无自报/无配对场景；运行定向、默认前端、全 Rust、生产构建与独立审查。

# Timeline and Foreshadowing Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. Track tests and independent review.

**Goal:** 作者能按故事位置记录事件，追踪伏笔铺设/回收及来源是否需复核。
**Architecture:** Material新增强类型元数据和第二来源，复用同库事务、回收与授权。核心、UI和transport按文件责任分工，最终集成审查。
**Tech Stack:** Existing Rust/rusqlite/React/Tauri, no new dependency.
**Spec:** docs/superpowers/specs/2026-11-17-tracking-design.md

## Global Constraints
仅云端；Windows暂停；无模型/外发/公网；不触用户真实数据；新类型外部只读，核心与Broker拒绝通用提案。

## Review Focus
- 来源或回收章节永久删除后，不丢正文，不变成当前版本。
- 状态变化校验来源，普通编辑旧基准允许保留；不能偷刷新revision。
- 并列故事位置稳定排序；GUI筛选不能丢草稿，外部ID游标不改变。
- v6非法跨书引用/半缺来源/非法状态必须原子拒绝。
- 通用资料提案提交与采纳均不能绕过新类型只读边界。

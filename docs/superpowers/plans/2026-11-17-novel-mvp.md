# Novel Studio Implementation Plan
**Goal:** Ship offline writing MVP and verified source package.
**Architecture:** React communicates with a single Rust application service through Tauri commands. A SQLite connection owns transactions; editor drafts are frontend state with serialized saves.
**Tech Stack:** Tauri 2, Rust, rusqlite, React, TypeScript, Vite.
**Spec:** docs/SPEC.md
## Global Constraints
Cloud only. Isolated test databases. No publication. No real user files. No claims of Windows verification without build evidence.
## Review Focus
- Late autosave must not overwrite newer text or another chapter.
- Chinese composition survives updates and navigation.
- Invalid backup leaves existing content intact.
- Export failure does not truncate existing output.
- Deleted works and descendants can be restored.

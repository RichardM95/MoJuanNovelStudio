# 双卷 TXT 导入至 SQLite 恢复与 TXT 导出验收

1. 从原创《苇门背潮》21 场景生成带 BOM、CRLF 的双卷 TXT。通过正式导入 API 核对预览和已存卷章身份、顺序及全部正文。
2. 保存第 21 场景的独立短稿。书级授权连接读取第 2 场景冻结引文与第 12 场景反例，提交有明确引用的建议。直接采纳拒绝；模拟作者逐项审阅后才能写入，核对历史。
3. 生成真实 SQLite 备份，再保存另一种正文。正式准备并提交恢复，检查恢复前快照确实保留后来编辑；重开活库核对目录、正文、历史与旧凭据失效。
4. 以独立预期完整字节检验 TXT 导出并读回文件。执行专项、全量 Rust 和未改动的前端默认测试/构建。此为小型固定验收，不是规模性能、GUI、人类写作或模型验收。

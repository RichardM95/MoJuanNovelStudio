# 大纲与前文引文对照

审阅页已支持保存「有疑问」和作者备注而不采纳。现有摩擦是两类精确引文与智能体自报冲突分在不同位置，作者须自行翻找。仅加一个默认折叠的只读对照，放在自报冲突附近。

只有本建议在本次加载的冻结包中含两类有效引用时才出现：大纲资料实际字段和前文章节正文。作者各选一条，界面才并排展示选中的冻结片段及名字、版本、标量范围；不默认选、不推断配对，不以是否有智能体自报决定是否显示。对照选择仅本次详情有效。无额外请求、无书库写入、无实时验证；不修改原引文展示、认可门槛或脏稿保护。不增加另一个审阅入口或语义引擎。

用原创互斥事件证明双引文和仅引大纲的两份建议都能合法待审；显式作者保留疑问才是语义判断，且不能采纳。无 Windows、真人或模型验收。

# 作品正文批量替换
用户持续授权完成既定离线写作路线；本轮由实现者选择尚缺的全书字面替换，不新增网络或模型。沿用Rust/React。相比直接全部替换，选用预览、人工二次确认和原子提交；不做正则、大小写折叠、资料/标题替换或跨书操作。

范围：当前活动作品内活动卷/章节正文。精确Unicode字面、非重叠匹配，可用空替换删除词，但搜索不可空或超256UTF8字节；替换不超1024字节。预览返回每章命中数及少量前后片段，点击章节按需读完整前后内容。最多500个受影响章节、32MiB候选原文与替换后正文总和、100000命中，超限整次拒绝绝不截断后直接提交。单章10MiB旧约束保持；扫描前预检全书活动正文合计不超过64MiB及100000章，超限拒绝。

候选只在本进程可信内存，随机ID、10分钟期限、最多一个待确认。预览冻结query/replacement及各章revision和身份链，确认检查epoch和完整活动章节清单/版本，防预览之后新增/删除/移动/改稿被漏改。使用同一Service锁及事务完成所有章save_in_transaction，保留每章历史、审计并令来源自然过期；不逐章独立提交。返回提交计数而非提交后重新load的结果。重复确认不得再执行替换。外部智能体无此入口。

界面进入前先flush；预览后改词必须失效旧确认，禁止迟到异步覆盖新输入。明确只替换正文、多少章多少处、历史可恢复。提交中阻止关闭；成功后单独reload，reload失败只重试读取。失败保留参数，冲突要求重新预览。不承诺批量一键撤销，单章历史恢复与整库备份保持可用。Windows验证暂停。

# 创作资料库最小纵向阶段

用户已要求先做功能、暂停Windows验证。本阶段沿用离线Rust/React/SQLite，不接模型、不外发稿件。

## 选择与边界
采用同库、书级隔离的资料卡，而非独立文件夹或外部知识库：同一Service事务、备份与授权可复用，避免旁路数据库。资料卡分设定、角色、大纲，点击单卡编辑，不把所有内容堆成列表。
- 设定字段：简介、题材、世界观、风格、规则。
- 角色字段：身份、性格、外貌、目标、关系、状态。
- 大纲字段：内容；可关联全书、一个卷或一个章，不是正文编辑前置条件。
- 资料独立标题；字段存字符串映射以便后续迁移扩展，本阶段只允许各类型已知字段。
- GUI新增、显式保存、版本冲突保护、软删除/恢复；无资料永久删除按钮。删除作品时资料保留，永久删除作品时同库级联。永久删除关联卷章时大纲解除关联而保留文本，并在同事务递增资料版本与更新时间，避免旧草稿覆盖。章节仅可在同作品内跨卷移动，拒绝跨书转移。
- 离开资料、切卡、关闭前有未保存内容则要求保存或保留原界面；失败不得丢草稿。显式按钮保存，暂不实现资料自动保存，减少草稿混淆。
- 外部智能体仅读资料列表元数据及单条正文。书级授权、父链回收、epoch、连接身份仍严格检查；无新写资料或直接采纳工具。现有章节提案人工审阅保持不变。
- JSON备份v4含资料及其回收状态，兼容v1/2/3；旧备份恢复为没有资料的旧库，恢复前验证SQLite快照保留当前全部内容。快照验证新增资料表。

## Builder calls
统一Material包含id/book_id/kind/title/fields/volume_id/chapter_id/revision/deleted_at/updated_at。关联仅大纲允许，volume_id与chapter_id最多一个且必须属于同书。资料已删除或关联父链回收时不可通过智能体读取。单卡字段总UTF8上限256KiB，全库资料正文32MiB，单书最多1000卡；不得自动清理资料。GUI只读列表不带fields，智能体列表分页默认50最多100，稳定id游标。

## 非目标
Windows编译/运行/IPC验收、外部模型、资料自动生成与智能体修改、关系图、全文检索、资料历史回滚。正文及已有审阅流程不重构。

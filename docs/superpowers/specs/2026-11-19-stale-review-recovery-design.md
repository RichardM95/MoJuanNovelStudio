# 过期建议的备注保留与下一轮

现状：来源已变的审阅保存被服务端拦住；只读回核未保存后，未保存备注继续阻挡关闭和换建议，需放弃修改。原地来源核对可报告已证实的版本或位置变化，保存操作的一般失败不能反推原因。

选择在已有 App 写作会话提供一个只读纯文本槽位。相比立即丢弃或仅依赖系统剪贴板，槽位可离开后在同一库、作品、章节重开读取；相比持久库新增记录，它不改写审阅数据或存档。点「保留备注副本并退出本次编辑」成功后才退出此次未保存编辑；无空位或超上限不修改草稿。仅保存备注和显示用资料名称，不保存判断、稿件、审阅凭据或可采纳状态。副本标示旧建议、应用关闭即丢失；本地剪贴板复制有单独的成功/失败提示。

作用域含库 epoch、会话库代次、作品、章及来源建议、包；新建议不继承备注或认可。其他范围不显示副本文字。读写结果不明仍遵守原有核对门槛。修复来源及重新冻结由作者明确操作，不绕过后端门槛，不覆盖原稿。

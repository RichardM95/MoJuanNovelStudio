# 资料上下文与人工审核闭环

用户继续已批准的后续阶段，沿用离线 Rust/React/SQLite。实现可追溯资料、作品内搜索与安全资料提案；不接模型、不传书稿、不开放公网，Windows验证保持暂停。

## 选择
采用既有同库资料卡的增量扩展。独立向量库/外部模型会扩大数据外传和运行环境，不采用。把所有资料混进章节正文会破坏TXT写作和检索边界，不采用。实现方案由开发者在用户授权路线内选择。

## 范围
- 增加摘要类型(content)，记录一条明确来源章节及其revision，与大纲目标关联分开。来源可用于其他资料。创建摘要需选择来源，资料保存不会悄悄更新来源版本。
- 服务端计算未记录来源、来源版本未变化、来源正文已更新待复核、来源不可用。版本未变不保证摘要语义正确。来源回收或永久删除不丢失资料文字，也不能自动把过期状态重置为最新。
- 书内字面关键词搜索章节标题/正文及资料标题/字段；仅活动同书内容，限查询长度、结果数和片段，显示类型并能打开命中项。无全文替换、外部搜索或向量检索。
- 外部智能体仅对已存在资料提出标题/字段和既有来源revision的更新建议。不能新建/删除资料，不能改变资料类型、所属书、关联或来源章节身份。服务端确定身份/原值，幂等键绑定完整载荷。
- GUI逐字段比较前后与来源基准，人工确认采纳。采纳同事务校验资料和来源版本，写资料/状态/审计；过期或失败不得覆盖。保留原值用于审核，不宣称已实现资料完整历史回滚。
- 撤回仅本人待处理提案；可信界面可拒绝过期提案。正文提案已有流程不变。
- 备份v5保存资料来源，兼容v1-v4；整库恢复清除未决运行提案并轮换epoch，恢复前已验证SQLite快照保留原库及审核数据。配额不自动删除旧内容。

## UI与安全
显式保存、dirty拦截、异步generation沿用。进入搜索/资料前保存正文；资料有草稿时不能采纳、切卡或关闭。搜索结果和提案是数据而非指令，以纯文本呈现。所有外部读写限定人工授权书。

# TXT导入为新作品
继续已批准的离线写作工具路线；当前只能新建和导出，已有长篇稿件无法分章导入。本轮选择本地UTF-8 TXT导入，不覆盖、不合并现有作品。相较自动直接写库，采用冻结文件、卷章识别预览、单章安全退路及二次确认。平台沿用Rust/React，无外部模型或稿件传输，Windows验证暂停。

读取最多16MiB，接受UTF-8及开头BOM；UTF-16/GBK/非法UTF-8/NUL明确拒绝，不猜测或有损解码。只移除文件开头UTF-8 BOM；其余正文及换行原样保留，不trim、不自动统一CRLF/LF。仅独立完整行形如第<数字>章/卷+可选标题作为结构，数字可中文常用数字及ASCII/全角数字；行最多200个字符，数字后必须章/卷，标题后缀须空白分隔，保守不识别叙述句。没有标题时全篇单章；标题前文字保留为前言，不丢正文。标题行转为元数据，不进入正文，标题后缀为空使用未命名章/卷。用户可切换“全文单章”，完全不识别标题，避免误判；该模式仍限单章10MiB，10至16MiB文件必须合理分章或整次拒绝。预览明确此规则，不能声称自动识别总正确。

冻结源文本在Service内单个可信候选；选择文件前可选headings或single模式，初次choose产生默认文件名书名/空作者/所选模式预览；自动分章超限可选择single后重新选文件；书名、作者、分章模式可改后重新预览，基于原冻结文本而非重新读路径。配置失败保留冻结源但标记不可提交，允许原ID重新配置；更新成功返回新随机ID，旧ID失效；错误ID不影响新候选；有效期10分钟，按需读取单章正文，列表仅名称/字节数/短片段。最多2000章、200卷，单章10MiB、元数据有界；正文总不超过源16MiB。标题/作者沿现有4096字节约束。

确认只提供冻结候选ID，不能注入任意章节payload。BEGIN IMMEDIATE中检查epoch和全库100000树记录及100000历史记录总量，分配新UUID并仅INSERT新作品/卷/章，初始revision0及对应初始历史/审计。失败整体回滚，不触碰旧作品或源文件；同名书允许但始终新ID。匹配候选提交尝试一次性消费，重试不可创建重复书；响应未知先读取书架核对，不自动重发。提交后返回新book_id/计数，不load造成成功误报。

UI书架入口打开前先flush，选择文件无需确认写库；必须已预览当前书名/作者/模式且二次确认后写库。改输入失效旧确认及迟到详情。提交/核对期间阻止关闭，成功与reload分离；刷新失败仅重试读取。取消释放自己候选，超限整次拒绝，不截断导入。CLI/MCP无此能力。没有GBK自动转换、合并导入、智能书名作者识别或逐章拖拽重排预览；导入完成后可用编辑器整理。

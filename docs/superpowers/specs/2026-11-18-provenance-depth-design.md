# 阶段2：原创前文修订后的依据重建

基线119eb8f/Library v10。已存在分散的前文及伏笔变更保护测试，本阶段把同一原创故事的设定、来源资料、正式伏笔、冻结包与待审建议贯通。用户授权深度验证，不扩大功能；云端隔离，无Windows/用户设备/模型或外发。

复用原创生产导出v2，以独立分支小矩阵保留目标正文：设定规则修改、前文改字但保留原引文字节、跨卷移到目标后、来源章回收。每例先建立当前包、合法待审建议与作者审阅，保存完整冻结证据。变更后旧提交/审阅/采纳不得继续，目标历史不变；旧引文与冻结位置可追溯。不得自动宣称伏笔已回收。

精确语义：资料source_status依章版本/存在性；正式occurrence还比较位置。跨卷移动时资料可以current而出现记录stale；回收为unavailable。不得强行统一stale或要求移回原位永久stale。章节位置变化同时阻止不再属于目标前文的引用。

正向选择正文修改例：普通资料保存不刷新来源；作者明确核对新source_revision，旧出现记录可恢复回收保留证据，以新版本精确片段创建新记录，然后新包/建议/作者审阅才可采纳。旧建议仍不可重用。真正关闭重开SQLite核对新旧证据及历史。设置修改例另验证新规则进入新包，不要求自动检查语义。

实际组件/JSDOM模拟桥用原创字段分别展示来源stale/unavailable、明确复核操作、原引文/位置不自动改写。可以集中测试最关键组件，不声称全原生串联。优先真实服务断言，缺陷先最小复现报告再修复。测试与生产模型保持边界，完整审查回归后同一Library更新。

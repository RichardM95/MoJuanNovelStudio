# 长篇持续修订规模验收

基线50dc1fb/Library11。用户优先真实可靠性而非测试数量。选择3卷24章、每章约8192 Unicode标量的确定性原创生成稿，普通生产保存到1/32/128次修订，约20万标量当前稿、约72MiB历史。实际字节/行数记录，不宣称文学连贯性或极限规模。现有64MiB测试直接SQL灌历史不替代正常保存证据。

独立opt-in工具，不增加默认suite负载、不引入依赖、不改产品。生产Create/Save建立样本，独立子进程分阶段记录已编译profile、wall/user/system CPU、Linux peakRSSKiB及DB/WAL/备份/留底实际大小。操作内Instant记录保存24次的分布、open/load、分页历史首屏/详情、全书检索、TXT预览和真实写入。编译/生成成本单列；不清缓存，不声称独享硬件。

最终JSON备份超过64MiB明确拒绝且数据不变；SQLite生产后台导出、准备、确认、重开恢复可靠。独有后写稿必须留在恢复前快照；先验证原样发布快照可恢复再打开读写。用确定性每章每版本内容验证，不只数行。实际CAS冲突和恢复预览过期拒绝不得损失正文/历史。备份恢复最多3轮，逐轮报告不是统计稳定承诺。保存增长是完整快照不是增量，区分预期线性空间和泄漏。

资源护栏：工作区隔离目录，不用小/tmp存主体；整体预算30分钟、磁盘2GiB、进程RSS2GiB，至少保留2GiB空闲。达到即中止并报告未完成，不绕权限或隐瞒。对sqlite512MiB/JSON64MiB/TXT32MiB等限制按源码核实。无Windows/原生UI/用户电脑/真实稿件/模型/外发/物理故障声明。若测到实际缺陷先因果复现报告，再另行最小修复；不以一次变慢进行重构。独立审查和回归后同一Library交付工具、结果摘要，生成DB/日志不入源码包。

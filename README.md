# 墨卷 · 离线小说写作

墨卷是一款 Windows 小说写作软件。你可以在同一个作品里写正文、排卷章、整理人物和设定，也能查找前文、回看旧稿。作品保存在自己的电脑上，写作时可以离线使用。

目前为 0.1.0 源码预览版，可在 Windows 上从源码构建安装包。安装、升级和卸载流程仍待实机验证。

## 开始写作

- **从头写一本书**：在书架点「新增作品」，填好书名，再添加卷和章节。
- **接着写已有的稿子**：在书架点「导入TXT」，可按标题分章，也可把全文放进一章。正文、设定和大纲分散在多个文件里时，可以用「导入作品文件夹」，先预览，再选要导入的内容。
- **继续修改**：正文会自动保存，也可以按 `Ctrl+S`。需要找回旧稿时，在作品内打开「改稿与历史 → 章节历史」，对照后选择要恢复的版本。

## 写长篇时可以用到

- **整理卷章**：调整章节顺序、跨卷移动章节，或在光标处把一章拆成两章。
- **整理人物和设定**：在「创作资料」里记录角色、世界观和大纲，并关联到对应章节。
- **梳理剧情**：用时间线记录故事事件，在「全书伏笔」查看伏笔在哪里埋下、提示或回收。
- **查找和改词**：用「书内搜索」找作品里的正文和资料。需要统一改人名或地名时，可以先预览「批量替换」的结果再确认。
- **审阅写作建议**：如果你使用外部写作助手，可以在作品内通过「智能体连接」授权它查阅这部作品的前文和资料。是否采纳建议由你决定。[连接说明](docs/AGENT-INTERFACE.md)

## 导出和备份

- **分享稿件**：在作品内点「导出 TXT」，可以导出全书、单卷或单章。
- **找回误删内容**：在回收站恢复作品、卷、章节或创作资料。
- **搬家或留底**：换电脑前，用「备份书库」保存整套书库，包含章节历史、创作资料和回收站。使用「恢复备份」会替换当前书库，确认前可以先查看备份内容。

## 从源码构建

在 Windows 上准备好 Node.js 22 LTS、Rust（MSVC）、Visual Studio Build Tools（C++ 桌面开发和 Windows SDK）以及 WebView2。在源码目录打开 PowerShell 并运行：

```powershell
./scripts/build-windows.ps1
```

构建完成后，可在 `src-tauri/target/release/bundle/nsis/` 找到安装包。

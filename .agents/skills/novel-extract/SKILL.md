# 完本小说深度拆书

**选底稿。** 仓库内作品先看[作品导航](../../../project/AGENTS.md)。直接拆书读取指定正文；接在[TXT 清洗](../novel-txt-clean/SKILL.md)之后时读取清洗副本，将清单中的原稿路径和两个 SHA-256 记入来源。多卷按作品内卷章顺序排列，合订稿与分卷稿择一作为主文本。资料卡、旧大纲、作者后记和状态卡可帮助定位，在正文中核实后再据此叙述事件。

**建索引。** 在新的结果目录记录底稿版本、文件名、卷章原题及其在对应文件的一基行段。保留重号、无号番外、残章与缺章占位，卷内重号用卷名区分。无明确分卷可按剧情阶段组织，总结中标记“整理分段”。用户只给样章时，所有交付注明覆盖范围。

**逐章读，再合卷。** 按上下文容量分批，每批读完整章节并保存章级笔记及最后完成的卷章。记录起始局面、行动与动机、转折、结果、角色新知、设定首次出现或变化，以及待追踪线索。中断后按底稿版本与索引续接。每批将完成项与索引对齐，合卷时回查跨章因果、别名、倒叙和伏笔回收点。分析性归纳标“推断”，后人补写标“补写”；冲突同时列出两处依据。

**默认交付。** 以 Markdown 交付下表内容，若用户指定专题则只交付对应部分。每项用“卷／章（节）”关联索引；异文、身份揭晓、时间冲突等需要精确定位时附文件与行段。没有证据的字段留作待核。

| 资料 | 内容与结构 |
|---|---|
| 书名_核心设定与卷纲.md | 梗概写清起因、主要转折和结局；设定写规则、适用条件、代价与例外；每卷写目标、转折、结局以及与下一卷的因果。真实卷纲用三级标题，如 `### 第一卷 卷名`，下方写卷纲正文。 |
| 书名_分章大纲.md | 每章一行，如 `- **第1节：发端** — 本章的起因、行动和结果。` 保留原序号、单位和章名。卷内重号时按卷分别输出，单卷文件的一级标题写明“第几卷”，导入时逐卷核对。 |
| 逐章详纲 | 以卷为文件、原章题为小节，展开场景、人物选择及前后因果。缺章只记录缺口。单行章纲是详纲的摘要。 |
| 人物、势力、地点与物品全鉴 | 以实体为条目，列名称／别名、关系或归属、首次出场和关键变化。身份揭晓注明读者何时可知。 |
| 时间线与伏笔表 | 时间线区分叙述顺序与故事时间；伏笔按铺设、再提示、回收分别定位。疑似呼应标“推断”；未见回收时注明已查范围。 |

**验收。** 索引中每个章节有提要或缺失说明；逐章详纲与章纲的卷章数一致。抽查开篇、卷间转折和结尾能否回到正稿，检查伏笔两端、核心设定的限制及所有补写标记。若用于墨卷文件夹导入，把目标 TXT、核心设定与章纲放在同一导入目录的顶层；在预览中核对识别的卷纲、章纲和关联，重号或异名项保留人工核对。

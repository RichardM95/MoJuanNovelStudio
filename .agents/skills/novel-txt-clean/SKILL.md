# 小说 TXT 清洗

确认作品与版本；同书多份 TXT 时按[作品导航](../../../project/AGENTS.md)确定底稿。脚本按物理行处理，保留未删行的字节、原顺序、BOM 和换行。自动移除完整匹配的独立站点行和明确的求票或更新通知，其余候选保留供语境复核。

**运行。** 使用 Python 3，从仓库根目录运行，最后一个位置参数用尚不存在的目录。脚本只依赖标准库。

```powershell
python ".agents/skills/novel-txt-clean/scripts/clean_txt.py" "作品.txt" "清洗初稿"
```

默认按 BOM、UTF-8、GB18030 识别；查看首尾及中段中文是否正确，旧编码有歧义时用 `--encoding gbk` 或 `--encoding big5` 等显式指定。输入解码失败时保留原件。结果目录中有 TXT 副本和 UTF-8 的 `清洗清单.json`。行号从 1 开始，`text` 包含原换行，删除行号可用于清洗稿与原稿的定位换算。

**复核。** 在原文中连读候选的前后段和章界。将独立求票、书友群推广、更新事务、作者问候计为附言；正文里的角色对白、戏中广告、剧情后记、缺章占位及正文附言混排行保留。仅凭括号、URL 或“作者”二字不足以删除。抽查每种自动删除模式及章首、章尾；同时观察反复出现而规则未识别的站名或标记。

复制清单，在副本中只调整经核实条目的 `action`（`remove` 或 `keep`）。逐行确认独立作者栏的边界；其中包含设定说明或叙事的行继续保留。对发现的漏标纯广告可在复核清单的 `additional_removals` 数组中附原稿的一基 `line`、完整 `text`（含原换行）及 `reason`。对同一原稿重跑到新目录：

```powershell
python ".agents/skills/novel-txt-clean/scripts/clean_txt.py" "作品.txt" "清洗定稿" --review "复核清单.json"
```

**交付。** 对照删除清单，核查副本只少了所列行，卷章标题及其顺序一致，报告删除数、保留待核项和输出位置。用户只要求清洗时到此完成；同时要求拆书时，将副本和清单交给[完本提取](../novel-extract/SKILL.md)。

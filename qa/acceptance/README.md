# 《雾港校钟人》原创单章验收样本

`single-chapter.json` 是 Rust 与 React 共用的唯一稿件数据源。一个虚构作品、一个卷、两个短章：第一章《铜牌初见》是已保存前文；第二章《第二声钟》是唯一候选目标。资料有设定、角色、目标章大纲、已有伏笔卡各一张，另有一条前文引文。未使用任何现有稿件、真实人物地址或模型。

| 正文 | Unicode 标量 | UTF-8 字节 |
|---|---:|---:|
| 前文 | 38 | 111 |
| 目标原稿 | 34 | 100 |
| 正常候选 | 51 | 150 |
| 违规候选 | 56 | 165 |
| 未保存作者稿 | 27 | 80 |
| v2 已审未决返工稿 | 40 | 117 |
| v4 新返工稿 | 60 | 177 |

值守规则：钟响期间不能离开值守台；钟只响两声，中间停三息。作者另核对事件顺序、弦栖只记所见及铜牌伏笔未揭晓。两份固定建议用同一套引文；违规候选只改变值守行动，且**没有自报冲突**，由脚本模拟可信作者标出冲突，再明确拒绝。正常候选的“符合”也只是作者脚本决定，引用存在不等于文义符合。不推断模型生成质量或文学连贯性。

## JSON 契约

- `schema_version`、`work`、`volume`、`prior`、`target`：展示名称、作品作者标记、原始正文和未保存草稿。卡片以 `key` 标识；两层各自映射为实际 ID。大纲的 `chapter: target`、伏笔的 `source: prior` 指章节槽位。
- `goal`、`materials`、`occurrence`：约束目标、必需资料及前文的已登记伏笔片段。引文范围是零基、左闭右开 **Unicode 标量**，不是 UTF-16 或 UTF-8 偏移。
- `citations`：两份建议共用的冻结依据；`entry` 是资料键或 `prior`，`field_key: occurrence` 由测试绑定本次生成的出现 ID。`quote` 独立声明预期片段，不作为 agent 提交参数。
- `accepted`、`rejected`：候选原文、独立重放键和逐卡作者判断/备注。`target.dirty_body` 是未保存的独立稿，不参与正式导出。
- `rework`：在原 v2 上留下已逐卡审阅的独立待决候选；历史返工至 v4 后用新冻结包提交不同候选，可信作者重新审阅，v5 正文为 `fresh_body`。两份都是同一故事的固定虚构稿。
- `export`：目标单章，不含卷章标题或作品元数据，CRLF、UTF-8 BOM；`visible_text` 不含 BOM，含章尾两次 CRLF。JSON 中的 `\r\n` 是解码后的两个原始字符。DOM 的 textarea 会把 CRLF 显示为 LF，不能据它确认原始字节；真实字节证据在 Rust 层。

Rust 验收沿用这份样本：真实采纳稿 v2 经生产备份任务导出 SQLite 后，可信测试作者在同章追加一句可识别的试验标记，保存为 v3，不使用 `target.dirty_body`。成功恢复后，重开的主库仍按 `export` 写出 157 字节的 v2 TXT；直接用发布的恢复前快照预备候选并取消，再单独打开该快照核对 v3 及其全部历史。这个续段不增加作品或章节，也不是 App 模拟桥、原生恢复对话框或生产 socket 验收。

章节返工使用生产导出 v2 的隔离副本（不是换过 epoch 的主库），经历 v3 的原稿字节、v4 的原采纳稿字节，仍拒绝 v2 包/审阅的写入；v5 经新的作者决定后，实物导出按同一选项为 184 字节。实际 App 用同一原创片段走历史确认及草稿保存保护，桥接为虚构。

命令与证据矩阵见 [验收索引](../../docs/ACCEPTANCE.md)。本样本不代表 20–30 章、长篇容量或性能测试。

前文修订续段也从原生产 v2 导出分别复制四个 SQLite：设定规则三息改五息；《铜牌初见》末尾追加潮泥句（冻结引文仍是同一 CRLF/🌙 字节）；移到排在目标之后的「退潮」卷；回收来源章节。每个副本先有独立的已审待决建议。正文修改例显式更新资料来源、回收并重新登记出现，再走新包、新建议、新审阅与 v3 采纳，另核对目标和来源历史。该续段的写建议用进程内生产 Broker，其他操作用生产 Service；React 的相同故事字段来自此 JSON，但桥接响应是合成的。

## 《苇门背潮》跨卷短节样本

`longrange-foreshadow.txt` 是另一部独立虚构作品，UTF-8、每行「标题 + 一个制表符 + 正文」，行号就是故事章次。第一卷为第 1–12 章，第二卷为第 13–21 章。前 20 行正文作为已保存前文；第 21 行正文仅作为候选，测试另存作者简短原稿，不把候选预先写入章节。共 21 个原创短节，不是 21 章完整长篇。

复现与证据范围见[跨卷伏笔验收](../../docs/ACCEPTANCE.md#跨卷远距伏笔苇门背潮)。

## 《汐灯阁》披露时点短样本

`setting-disclosure.json` 包含同一条设定、唯一让人物本人获知的开匣场景、前后候选和四个供阅读的对照片段。文件不附预期审阅标签；测试脚本的作者判断和运行方法见[验收索引](../../docs/ACCEPTANCE.md)。这是一组短场景对照，不是模型生成或长篇文学验收。

# 番茄章稿离线实验

解压后直接用浏览器打开本目录的 `index.html`。不必启动墨卷或服务器，也不需要账号；页面内只有两卷六章虚构样稿。请勿粘贴真实稿件。

- **A**：点「创建章节」，从左侧样稿手填目标卷、章号、标题、正文。
- **B**：点「创建章节」后，再点「填入本章」。
- **C**：只点「准备下一章」。这个按钮仅在本地模拟器中出现，不能操作真实网站。
- 各组都检查四个字段 → 点「核对完成」 → 再点「存模拟草稿」。同一目标卷和章号不得有两条记录。结果不一致就停在当前章，可修正后核对。
- 实验组完成后可导出 CSV。记录不上传，刷新或关闭页面即清除；重复整组会替换该组统计。

**人工对照。** 先练习一次，再做正式采样。建议第一轮 A→B→C，第二轮 C→A→B，第三轮 B→C→A；每轮临关闭前导出自己的 CSV。保持电脑、输入法和鼠标方式相同。计时从展示待填稿到点击「核对完成」，另计到存稿的总秒数；「操作」统计组内关键按钮和字段编辑轮次，不计每个键。核对错误、误填、漏填和重章都记下。比较中位耗时，同时检查是否有内容错误；C 只有在 B 基础上确实省事，才值得验证在真实后台的可行性。

**不能据此推断。** 这里不是番茄后台，未验证它的编辑器、自动保存、真实草稿恢复或平台是否允许自动操作。自动化点击只能验证流程正确，不能代替实际人工计时。
